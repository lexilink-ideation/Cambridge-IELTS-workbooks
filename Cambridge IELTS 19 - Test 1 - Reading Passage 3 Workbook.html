📋 Passage Overview

The persistence and peril of misinformation. Brian Southwell examines why false information spreads and why it is so hard to correct. He makes three key observations, contrasts the philosophers Descartes and Spinoza on how we judge truth, and discusses regulation and correction campaigns. Question types: multiple choice, summary completion (from a list) and Yes/No/Not Given.

💡 Reading tip: For YES/NO/NOT GIVEN you must match the writer's claims/opinions, not just facts. And in the list-of-phrases summary (Q31–36), first decide the grammar (noun? adjective phrase?) each gap needs, which quickly rules out several options.

🔍 Complex Sentence Analysis

However, we currently live in an era in which technology enables information to reach large audiences distributed across the globe.
Main ClauseWe currently live in an era.
Subordinate / Relative'in which technology enables information to reach large audiences' (relative clause) + 'distributed across the globe' (reduced relative).
Grammar Note'in which' = where; 'distributed…' reduces 'that are distributed'.
Simple MeaningToday, technology lets information reach huge audiences everywhere.
中文然而，我们如今生活在一个技术能让信息触达全球广大受众的时代。
Descartes argued that a person only accepts or rejects information after considering its truth or falsehood; Spinoza argued that people accept all encountered information by default and then subsequently verify or reject it.
Main ClauseDescartes argued X; Spinoza argued Y.
Subordinate / RelativeTwo 'that'-clauses report each philosopher's view; the semicolon balances the contrast.
Grammar NoteParallel reporting verbs ('argued that…') set up a direct contrast.
Simple MeaningDescartes: we judge first, then accept. Spinoza: we accept first, then judge.
中文笛卡尔认为人只有在思考真伪之后才接受或拒绝信息；斯宾诺莎则认为人默认接受所遇到的一切信息，随后再加以验证或否定。
People appear to encode all new information as if it were true, even if only momentarily, and later tag the information as being either true or false.
Main ClausePeople appear to encode all new information as if it were true.
Subordinate / Relative'as if it were true' (unreal comparison) + 'even if only momentarily' (concession).
Grammar Note'as if + past subjunctive (were)' marks an unreal comparison.
Simple MeaningAt first we treat everything as true, then later label it true or false.
中文人们似乎会把所有新信息都当作真的来编码，哪怕只是一瞬间，之后再把它标记为真或假。
For corrective campaigns to be persuasive, audiences need to be able to comprehend them, which requires either effort to frame messages accessibly or effort to educate audiences about misinformation.
Main ClauseAudiences need to be able to comprehend the campaigns.
Subordinate / Relative'For corrective campaigns to be persuasive' (purpose infinitive) + 'which requires…' (relative comment clause).
Grammar Note'For + noun + to-infinitive' expresses a condition/purpose.
Simple MeaningTo convince people, correction campaigns must be easy to understand.
中文要使纠错宣传具有说服力，受众必须能理解它，而这需要把信息表达得通俗易懂，或教育受众认识虚假信息。

🧠 Reading Logic Training

Signposting by number: 'First of all… Secondly… Thirdly…' lists the three observations. The passage structure follows this, so each observation maps to a later paragraph.

Contrast of thinkers: Descartes vs Spinoza — judge-then-accept vs accept-then-judge. Recent 'empirical evidence… supported Spinoza's account'. Track who wins the argument.

Cause & effect (brain): because 'skepticism physically reside[s] in a different part of the brain' than encoding, we accept first and doubt later. This links Q36 (different locations).

Concession about regulation: FDA programs are 'laudable and useful' BUT 'do not keep false advertising off the airwaves' — a positive point immediately qualified.
